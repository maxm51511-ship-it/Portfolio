Autonomous 3D print removal arm

WhenNov 2026
WhereViam Robotics Hackathon, IEEE NJIT
My roleTeam member

A one-day hackathon build: an arm that removes finished prints from a 3D printer so the printer can run unattended.

What I did

  • Prototyped the system on a UFactory xArm 6 with a gripper and an arm-mounted Intel RealSense depth camera, integrated through Viam.
  • Built and labeled a custom image dataset and trained a YOLO detection model to classify failed prints versus good prints.
  • Designed a closed-loop workflow that verifies the bed is cleared and restarts jobs.
  • Planned next step: G-code analysis so the system can warn about failures early.
